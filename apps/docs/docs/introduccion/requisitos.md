# Requisitos del Sistema

## Para Alumnos (App Móvil)

- Dispositivo Android (API 26+ / Android 8.0+) o iOS 14+.
- Micrófono funcional para captura de audio a 44.1 kHz.
- Cámara frontal o trasera para captura postural a 30 FPS.
- Espacio libre de almacenamiento: ~300 MB.

## Para Docentes / Administradores (Web Admin)

- Navegador web moderno (Chrome, Firefox, Safari, Edge) con soporte WebAssembly.
