# La Zampoña / Siku

Flauta de pan andina compuesta típicamente por dos hileras complementarias: **Ira** (6 tubos, líder) y **Arca** (7 tubos, seguidor).

- **Afinación:** Escala diatónica en Sol Mayor / Mi Menor.
- **Técnica:** Soplado perpendicular en el borde de cada tubo, técnica de diálogo trenzado.
- **Visualización:** Matriz de dos filas de tubos con resaltado del tubo activo.
