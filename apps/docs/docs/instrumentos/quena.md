# La Quena

Aerófono andino biselado tradicional con 6 orificios superiores y 1 orificio inferior para el pulgar.

- **Afinación estándar:** Sol Mayor ($Sol_4$).
- **Digitación:** Representada mediante oclusión de 7 orificios ($[0, 1]$).
- **Postura esperada:** Ángulo de codos entre 45° y 60°, cabeza erguida, bisel apoyado en el labio inferior.
